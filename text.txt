1. Scroll Reveal (появление при скролле)
Элементы появляются с анимацией при прокрутке страницы.

Библиотека: Intersection Observer API (нативный) или AOS, ScrollReveal.

Где применить: Секции "Услуги", "Афиша", "Труппа театра" — карточки вылетают снизу или сбоку.

2. Lazy Load (ленивая загрузка изображений)
Картинки загружаются только когда пользователь доскроллит до них.

Библиотека: lazysizes или нативный loading="lazy".

Где применить: Все картинки в галереях, афишах, труппе.

3. Parallax (параллакс-эффект)
Фон движется медленнее, чем контент.

Библиотека: Parallax.js, Rellax или CSS с transform: translateY().

Где применить: Главная секция (фон), секция "О театре" (фоновый текст или изображение).

4. Typing Effect (печатающий текст)
Текст появляется по буквам.

Библиотека: Typed.js, TypewriterJS.

Где применить: Заголовок на главной "Театр, который вдохновляет" или слоган.

5. Tabs (вкладки с анимацией)
Переключение вкладок с плавным переходом.

Библиотека: Простой JS + CSS transitions.

Где применить: В секциях "Афиша" (дни), "Труппа" (актёры), "Услуги" (описания).

6. Accordion (аккордеон)
Раскрывающиеся блоки с анимацией.

Библиотека: Простой JS + CSS transitions.

Где применить: В секции "О театре" (подробное описание), в "Услугах" (детали).

7. Smooth Scroll (плавный скролл)
Плавная прокрутка к якорным ссылкам.

Библиотека: smooth-scroll или нативный scroll-behavior: smooth.

Где применить: Меню навигации (ссылки на секции).

8. Count Up (счётчик)
Числа увеличиваются до целевого значения.

Библиотека: CountUp.js или animate-number.

Где применить: В секции "О театре" (количество спектаклей, лет работы, награды).

9. Fade In (появление с прозрачностью)
Элементы плавно появляются при загрузке или скролле.

Библиотека: CSS анимация + Intersection Observer.

Где применить: Все заголовки, карточки услуг, афиши.

10. Hover Animations (анимации при наведении)
Карточки слегка поднимаются или меняют цвет при наведении.

Библиотека: CSS transitions.

Где применить: Карточки "Услуги", "Афиша", актёры в "Труппе".

11. Parallax Scrolling (параллакс при скролле)
Фон движется с разной скоростью.

Библиотека: ScrollMagic, Parallax.js.

Где применить: Фоновая картинка на главной секции.

12. Particle Effect (частицы)
Плавающие частицы на фоне.

Библиотека: particles.js, tsparticles.

Где применить: На главной или в "О театре" (для атмосферы).

13. Progress Bar (полоса прогресса)
Показывает прогресс чтения статьи.

Библиотека: ProgressBar.js.

Где применить: В "О театре" или в "Афише".

14. Shuffle (перемешивание)
Элементы перетасовываются с анимацией.

Библиотека: Shuffle.js.

Где применить: Галерея актёров в "Труппе" (сортировка по ролям).

15. Timeline (хронология)
События появляются с анимацией при скролле.

Библиотека: TimelineJS.

Где применить: В "О театре" (история создания).

16. Marquee (бегущая строка)
Текст бесконечно двигается.

Библиотека: Marquee.js.

Где применить: Подвал сайта или верхняя полоса с новостями.

17. Ripple Effect (волны при клике)
При клике на кнопку появляется круговая волна.

Библиотека: Нативный JS + CSS.

Где применить: На всех кнопках ("Купить билет", "Смотреть афишу").

18. Glitch Effect (глитч-эффект)
Текст или изображение искажается как при помехах.

Библиотека: Glitch.js.

Где применить: Заголовок на главной.

19. Morphing (морфинг)
Одна форма плавно превращается в другую.

Библиотека: MorphSVG.

Где применить: Иконки в "Услугах" (при наведении).

20. Scroll Snapping (прилипание скролла)
Секции "прилипают" при прокрутке.

Библиотека: CSS scroll-snap-type.

Где применить: Главная страница (секции как слайды).

21. Cursor Animation (кастомный курсор)
Прикольный курсор с эффектами.

Библиотека: MagicMouse.js.

Где применить: По всему сайту.

22. Text Reveal (появление текста)
Текст появляется по словам или буквам.

Библиотека: TextReveal.js.

Где применить: Заголовки секций.

23. Spotlight (прожектор)
Эффект круглого света, который двигается за мышкой.

Библиотека: Spotlight.js.

Где применить: Фон главной секции.

24. Star Rating (рейтинг звёздами)
Анимация заполнения звёзд.

Библиотека: StarRating.js.

Где применить: В "Отзывах".

25. Glassmorphism (стеклянный эффект)
Прозрачные блоки с размытием.

Библиотека: CSS + JS (background blur).

Где применить: Карточки "Услуги", модальные окна.

26. Neumorphism (неоморфизм)
Мягкие тени с эффектом "выдавленности".

Библиотека: CSS + JS.

Где применить: Кнопки и карточки.

27. Infinite Scroll (бесконечная прокрутка)
Контент подгружается автоматически.

Библиотека: InfiniteScroll.js.

Где применить: В "Афише" (если много спектаклей).

28. Grid Animation (анимация сетки)
Ячейки сетки появляются с задержкой.

Библиотека: Grid.js.

Где применить: Галереи, "Услуги".

29. Flip Card (переворачивающаяся карточка)
Карточка переворачивается при наведении.

Библиотека: CSS + JS.

Где применить: В "Труппе" (актёры — фото/роль).

30. Video Background (фоновое видео)
Видео на фоне с автозапуском и mute.

Библиотека: Video.js или нативный HTML5 video.

Где применить: Главная секция.

Рекомендация для вашего макета:
Начните с:

Scroll Reveal (появление секций при скролле) — AOS.

Typing Effect (печатающий текст на главной) — Typed.js.

Parallax (для фона) — Parallax.js.

Hover animations (карточки услуг и актёры) — CSS transitions.
